# Settings

Changes are applied and saved as you make them.

The search box at the top shows only the sections that mention what you type (try "volume" or "colour").

| Setting | What it does |
|---|---|
| Loudest volume | How loud the slider gets at the top, 30 to 150 percent. Above 100 percent a warning shows: see [Playback and sound](06-playback-and-sound) |
| Gapless playback | Start the next song a moment early so there is no pause |
| Play songs at the same volume | Even out loud and quiet songs |
| Play through | Which sound output to use. System default follows your desktop, including earbuds switching on and off |
| Earbuds | Use earbuds, Hand to phone and Turn off buttons. Only shown when [Maid BT](https://github.com/Maidware-Project/Maid-BT) is installed |
| Album art size | How big the cover gets on the Now Playing page, 240 to 900 pixels |
| Theme | Sleeve (your own colours and the seasons) or Dusk: peach on warm brown and slate, with a background that stays put whatever is playing. A theme replaces your accent colour and the seasonal looks until you go back to Sleeve |
| Seasons and holidays | Off, Seasons, Holidays or Both. Season: follow the calendar, or Spring, Summer, Autumn, Winter. Holiday: follow the calendar, or Christmas, Halloween, New Year |
| Accent colour | One of 16 bold colours, or Custom… to pick any colour you like |
| Match the colours of the song | The accent follows the cover of the song that is playing |
| Show what I'm listening to on Discord | Off by default. Needs your own Discord Application ID, see [Playback and sound](06-playback-and-sound) |
| Also show the album cover | Adds the cover to the Discord status, looked up on MusicBrainz and the Cover Art Archive |
| Check for updates / Update now | Asks GitHub for the newest release when you press it (never by itself) and installs it into Sleeve's own folder. A newer build of the same version counts. Only for a copy made by `install.sh` |
| Uninstall Sleeve | Asks whether to remove Sleeve only (your music, playlists and settings stay) or Sleeve and all its data. The second lists what it will delete, then asks again. Audio files are never deleted |
| Remember what I listen to | Keeps which songs you play, on this computer only, for the Listening tab on the Identity page |
| Clear listening history | Deletes that list |

Where you left the volume slider, the window size and the last page you used are remembered too.

The Settings page also shows where things are kept: your music folder, `dl.py`, the stashed songs file and the
settings file. Open music folder shows the folder in your file manager, and Rescan library re-reads it.

Show Spotify playlists is a button on the Playlists page. See [Playlists](03-playlists). More about sound is in
[Playback and sound](06-playback-and-sound).
