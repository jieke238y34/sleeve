# Keyboard shortcuts

| Key | What it does |
|---|---|
| Space | Play or pause |
| Left arrow | Back 5 seconds |
| Right arrow | Forward 5 seconds |
| F11 | Album art fullscreen |
| Esc | Leave fullscreen |
| Ctrl+B | Hide or show the player bar |
| Shift+Enter | Add the selected Library songs to the end of the queue (while the Library list has the focus) |
| Enter | Play the selected song in the queue (while the queue has the focus) |
| Esc | Unselect the song in the queue (while the queue has the focus; elsewhere it leaves fullscreen) |
| Ctrl+G | Pick up the selected song in the queue. Up and Down then carry the song (Home and End send it to the top or bottom) instead of moving the selector; Enter, Esc or Ctrl+G again puts it down |
| Delete | Remove the selected song from the queue (while the queue has the focus; the file is never touched) |
| Alt+Up / Alt+Down | Move the selected queue song up or down |
| Media keys | Play, pause, next, previous |

When you are typing in a box, or a list or button has the focus, Space and the arrows do their normal job there
instead.

The queue scrolls to follow the selected song, so it never slips off the edge.

## Change the keys

Settings > Shortcuts lists every action above with its key. Click a box and press the keys you want; **Reset** puts
the original back, **No key** leaves the action without one, and **Reset all shortcuts** undoes every change. If the
key you press already belongs to another action, it is taken from that one (the status bar says which) so one key never
does two things. The keys for the Library list and the queue only work while that list has the focus, so they may
share a key with each other. Esc for leaving fullscreen (outside the queue) and the media keys cannot be changed. A key without Ctrl or
Alt does nothing while you are typing in a box.

## Mouse tips

- Double-click a song to play it, or a folder to play everything in it.
- Click a highlighted row once to remove the highlight.
- Click on a slider to jump straight to that spot.
- Right-click songs for the menu.
